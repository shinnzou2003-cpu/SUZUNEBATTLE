■ GitHub Pages へのアップロード（全部入れ直す場合）
  1. リポジトリの古いファイルをいったん全部削除してコミット
     （anim・media は古い不要ファイルが残るとややこしいので、まっさらにするのがおすすめ）
  2. chrono-fight フォルダの【中身】をアップロード（index.html が一番上に来るように）
  3. ブラウザからは1回100ファイルまでなので、3回に分けます
     1回目：index.html, game.js, README.txt, assets, anim（計63個）
     2回目：media フォルダの中の voice と sfx（計85個）※ media フォルダを作ってその中へ
     3回目：media フォルダ直下のファイル（mp4・mp3・jpg、計28個）
  4. 反映まで1〜2分。スマホは再読み込みしてから遊んでください。
