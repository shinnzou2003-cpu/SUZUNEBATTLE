# KANNA（カンナ）追加 — 設定とゲーム設計 (2026-10-05)

9人目のファイター。『花守りの神機 / GARDEN OF THE GOD-MACHINE』『ORANGE』。設定は SZOU 提供。正式リファレンスは `refs/kanna_sheet.jpg`（デザインシート「KANNA — GARDEN GOD-MACHINE」2026-08-30確定）。

## 原設定（要約）
- 女性型の巨大バイオメカ神機。花のない白い廃墟の谷で何百年も眠り、胸の中で「最後の色＝花」を守ってきた神様の機械。無言・穏やか・年齢不詳
- パールホワイトの積層セラミック装甲＋アンバーオレンジの光の溝、露出した金のピストン、欠けた黄金のハロー、白い光ファイバーの髪（毛先がオレンジに発光）、背中の刃状フィン「花弁冠」、胸の金の虹彩コア（開くと肋骨装甲が門のように開き、オレンジの花園）
- 色：白×金×アンバーオレンジ。背景はコバルトブルーの空と白い廃墟。禁止：セピア・彩度落とし・雨・夜・読める文字
- 唯一のセリフ「こわして」。コピー：She was never built to win. She was built to bloom.
- 花弁ブレードは攻撃時に「開花」して展開、斬った軌跡は花弁型の光（直線の剣閃は禁止、必ず弧）。画面のオレンジの面積＝物語の進行度

## ゲーム設計（SZOU 指示：人の2.5倍の大型・超高機動・全身から花を出して戦う）
```js
kanna: { id: 'kanna', name: 'KANNA', role: '花弁冠・巨大神機', c1: '#ff8c28', c2: '#e8b85a', rgb: '255,140,40', rgb2: '232,184,90',
         speed: 6.6, jump: -25.0, anchor: .5, hurtW: 118, hurtH: 590, exName: '開花・花冠', ultName: '開花 ― ORANGE' }
```
- 大きさ：CHAR_SCALE 2.1（表示 約670px、SUZUNE の約2.5倍）。KANNA がいる間はカメラの寄りを `CAM.zGiant`(.84) までに制限してハローが切れないように。押し合い距離も広め
- 超高機動：歩き 6.6・ダッシュあり・通常攻撃は毎回大きく滑り込む
- a1/a2/a3：花弁冠の刃で横薙ぎ→斬り上げ→全方位の開花斬り。軌跡は全部オレンジ×パールの弧（fxPetalArc）。ヒットした場所の床に花が咲く
- b 花弁射出：背中の刃が5枚、花弁の刃になって誘導で飛ぶ（projectile type `petal`、通常攻撃で相殺可）
- ex 開花・花冠：花冠が全開して周囲を一閃 → 相手に向かって床から花の柱が5本連続で噴き出す（最後の1本で打ち上げ）
- ult 開花 ― ORANGE：ムービー → 胸の虹彩が開いて光を吸い込む → 花園が溢れ出す花弁の奔流（画面横断、ガードで削りのみ）→ 相手の足元から花の柱でフィニッシュ。発動中は白い世界がオレンジに染まり、終わった後もうっすら残る
- ULT 本編のアニメ（2026-10-05 追加）：専用のグリーンバック動画（12s）から ultCharge（両腕を広げ胸の装甲が開く）→ ultFire（両掌を前へ突き出す姿勢をループ）→ ultEnd（胸を閉じて構えに戻る）。背後に光の大輪が咲き（drawKannaUlt 背面）、胸の花園が輝き、花弁の奔流が相手へ伸びる（前面）。床の花は奔流と一緒に手前から奥へ広がり、フィニッシュは相手の足元に花の柱＋大輪（fx `blossom`）
- 床の花（`G.bloomFloor`）はラウンド中ずっと残る＝オレンジの面積が戦いの進行度
- ボイス：無言のキャラなので吐息・ハミング中心。EX「ひらいて」、ULT「こわして」、敗北「ごめんね」、勝利ムービーは「ら、ら、らー」のハミング
- ミラー時の色：オレンジ→水色
