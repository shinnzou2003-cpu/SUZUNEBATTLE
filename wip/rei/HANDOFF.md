## 原設定（要約）
- 月白 零 TSUKISHIRO REI／ツキシロ・レイ。異名「涙守（ナミダモリ）」THE LAST TEAR
- 外見年齢19・165cm・元人間の半生体式サイボーグ。所属なし。失われた痛みと記憶を守る者
- 月白色の切り揃えボブ。左目は淡い灰色の人間の眼、右目は朱色に発光する機械眼。右の機械眼から一筋の血涙（武器を完全展開するたび必ず一滴流れる。拭わない）
- 頬〜顎・首・両腕・脚の大部分が黒鉄と真鍮の機械。墨模様の擦れた黒い着物、肩に朱色の彼岸花
- 巨大な黒い機械笠＝武器の暴走を抑える制御装置。背後のケーブルは神経と武器を直結
- 寡黙で優しい。安易に慰めず、悲しみを抱えたまま立ち上がるまで黙って隣にいる。憎しみだけで刃は振るわない
- 専用武器「哭喰・彼岸 KOKUSHOKU-HIGAN」全長約3mの機械大太刀。普段は分割して背中に折り畳み。刀身に朱色の彼岸花紋、鍔は真鍮の牙を持つ獣の顎
  - 第一形態 大太刀形態：斬撃の瞬間に刀身内のピストンが連鎖作動し、遅れて二段目の衝撃（装甲を割り、遅れて核を砕く）
  - 第二形態 顎門形態：鍔の獣顎が開き、背骨部分が分離。ケーブルと装甲で拘束し、黒い墨に変えて飲み込む（刀身内部の「黒い浮世」に封印。吐き戻しも可能）
  - 最終形態 墨龍形態：刀身が装甲節に分裂し、鬣に朱色の彼岸花・朱色の機械眼の巨大な機械龍に。黒い墨溜まりから出現し、長大な身体で包囲して空間ごと飲み込む。大太刀は龍を封じる「棺」
- 翡翠の女主人（＝ENJO）との対立：「悲しみは、私が喰えば消える」／「消えた痛みは、救いじゃない」。善悪ではなく救済の方法の違い。肩の最も大きな彼岸花は最初に忘れた“大切な誰か”＝女主人の可能性（双方覚えていない）
- 代表セリフ：「この涙は、私が人間だった最後の証」「痛みを消したら、愛したことまで消えてしまう」「忘れたくないんじゃない。忘れたことさえ、忘れたくない」「哭喰――開け。あいつを、世界ごと飲み込め」「悲しみは傷じゃない。誰かを大切にした痕だ」

## ゲーム設計
```js
rei: { id: 'rei', name: 'REI', role: '大太刀・墨龍', c1: '#e8463c', c2: '#e9e4d8', rgb: '232,70,60', rgb2: '233,228,216',
       speed: 5.0, jump: -24.0, anchor: .55, hurtW: 50, hurtH: 280, exName: '顎門・哭喰', ultName: '墨龍・彼岸' }
```
- 色：朱（彼岸花・機械眼）と月白。黒鉄の世界に朱が差す
- a1/a2/a3：大太刀の斬撃。a3 は「二段目の衝撃」— 斬撃ヒットの約10フレーム後に刀身内ピストンの遅れ衝撃が同じ場所で炸裂（追加ヒット）
- b（必殺）二の太刀：踏み込み大振り＋遅れ衝撃の墨の衝撃波が地を走る
- ex 顎門・哭喰：鍔の獣顎を開いてケーブルを射出（ARIA のワイヤー同様の飛び道具）。捕まえた相手を引き寄せ、墨に変えて飲み込み→吐き戻して打ち上げ。ガードされたらケーブルは戻る。発動時に血涙が一滴
- ult 墨龍・彼岸：「哭喰――開け。あいつを、世界ごと飲み込め」。足元から墨溜まりが相手へ広がり、機械龍が出現→とぐろで拘束→画面が墨に呑まれる→吐き戻し。ガード可能（削りのみ、unblock 不使用）。発動時に血涙
- 機械龍のスプライトは ENJO の RINDO と同一デザイン（黒い機械龍・鬣に彼岸花・朱の眼）のため、同じ素材から REI のアトラスにも書き出す
