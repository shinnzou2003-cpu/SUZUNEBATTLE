## ゲーム設計
```js
ichika: { id: 'ichika', name: 'ICHIKA', role: '時間操作・1秒スロー', c1: '#f2c14e', c2: '#fff0c8', rgb: '242,193,78', rgb2: '255,240,200',
          speed: 5.8, jump: -25.5, anchor: .55, hurtW: 50, hurtH: 275, exName: 'ONE SECOND', ultName: 'ZERO SECOND' }
```
- 時間スローの仕組み：`G.chrono = { owner, k, t, life }`。owner と反対側（キャラ・弾・召喚獣）だけ k 倍速で進む（simStep で `sdt * chronoK(f)`、updateProj は弾の持ち主で倍率）。スロー中はステージと相手がモノクロ（ステージに saturation、相手は `ctx.filter = grayscale`）、ICHIKA はカラーのまま
- a1/a2/a3：ジャブ → 回し蹴り → かかと落とし（打ち上げ）
- b 踏み込み：踏み込みで相手が 24 フレームだけ .35 倍速 → 飛び蹴りで突っ込む
- ex ONE SECOND：踏み込み → 「ONE SECOND」のコミック文字 → 78 フレーム相手側が .14 倍速＋モノクロ。ICHIKA は普通に操作できる（この間にコンボを入れるのが狙い）
- ult ZERO SECOND：ムービー → 踏み込み → 時間停止（.02 倍）→ 止まった相手の左右に瞬間移動しながら6連蹴り（ダメージは溜めるだけで相手は動かない）→ 時間が戻った瞬間に全部まとめて当たる（約35）。ガードで削りのみ。専用のULTモーション動画（踏み込み→連続蹴り→構え直し）から ultCharge / ultFire / ultEnd
- AI：近づいたら ONE SECOND を使ってから攻める
