## ゲーム設計
```js
isana: { id: 'isana', name: 'ISANA', role: 'サルベージ海賊・錨', c1: '#00e5ff', c2: '#39ffb0', rgb: '0,229,255', rgb2: '57,255,176',
         speed: 4.8, jump: -23.5, anchor: .55, hurtW: 58, hurtH: 285, exName: '舷側斉射', ultName: '深淵錨・ダイブモード' }
```
- 重量級：歩きは遅め、リーチは長い。ダッシュあり（右かかとのウォータージェット想定）
- a1/a2/a3：アンカーカトラスの横薙ぎ → ハルシールドの盾打ち（押し返し）→ 錨を甲板に叩きつけ（打ち上げ＋床の衝撃）
- b アンカーショット：錨を鎖ごと投げる（projectile `anchor`）。当たるとウインチで巻き取って手元まで引き寄せ、追撃できる。ガードされたら跳ね返って戻る、通常攻撃で相殺可、本人が殴られたら鎖が外れる
- ex 舷側斉射 BROADSIDE（EN telop: BROADSIDE）：盾を据えて側面の砲門から6連射（projectile `cball`、放物線、相殺されない、最後の1発で打ち上げ）
- ult 深淵錨・ダイブモード（ABYSSAL ANCHOR : DIVE MODE）：ムービー → ウインチドラムから鎖3本が伸びて拘束 → 背面フィンが展開（シアンの噴射）→ 相手の頭上へ上昇 → 錨を下にして急降下、叩き込んでフィニッシュ（約26）。ガード可（削りのみ）
- ヒット演出：錆と緑青の破片＋シアンの火花（fxSalvage）
- ミラー時の色：シアン→錆オレンジ
- 勝利セリフ（仮）：「沈んだ勝ちでも、引き揚げりゃあたしの宝さ。」
